# The Watchers

A home for the **The Watchers** mascot system and future AI-news brand experiments.

The current starting point is a self-contained static mascot page in [`index.html`](./index.html). The mascots can later become recognizable editorial characters for AI news and short-form posts across web, Instagram, TikTok, Facebook, and other channels.

## Possible editorial roles

These are working concepts, not a locked content architecture:

- **Nerd Watcher** — models, tools, code, and technical explainers
- **News Watcher** — important AI news with context instead of noise
- **Signal Watcher** — jobs, trends, funding, products, and daily market signals

The roles can evolve independently from the distribution channel. The existing `industry-watcher` project remains separate; this repository is the brand and mascot playground for The Watchers.

## Status

Early prototype. Naming, characters, editorial formats, and channel strategy are intentionally open.
